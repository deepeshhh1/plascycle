# Plascycle ♻️

**Plastic waste recycling solution — 2nd Prize, State-Level Hackathon**

Plascycle is a project built to tackle one of the most visible environmental problems around us: plastic waste that never gets recycled. A large part of household and campus plastic waste is either burned or dumped because collection and segregation never reach the people generating it. Plascycle works on closing that gap — making it easier to segregate, collect and route plastic waste towards recycling instead of landfills.

## 🏆 Achievement

- **2nd Prize — State-Level Hackathon**

## 💡 The idea

- Spread awareness of plastic segregation at the source (wet / dry / plastic)
- Connect waste generators with collection and recycling pathways
- Encourage reuse and recycling habits among students and households

## 🛠️ Built with

- HTML, CSS and JavaScript (web platform)
