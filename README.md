# Plascycle ♻️

**Plastic waste recycling solution — 2nd Prize, State-Level Hackathon**

Plascycle is a project built to tackle one of the most visible environmental problems around us: plastic waste that never gets recycled. A large part of household and campus plastic waste is either burned or dumped because collection and segregation never reach the people generating it. Plascycle works on closing that gap — making it easier to segregate, collect and route plastic waste towards recycling instead of landfills, and turning collected plastic into usable products like sheets and furniture boards.

## 💡 The idea

- Spread awareness of plastic segregation at the source
- Connect waste generators with collection and recycling pathways
- Convert collected plastic wrappers into recycled sheets/boards — the web app includes a **material-requirement calculator** (wrappers needed per sheet thickness)

## 🛠️ Built with

- HTML, CSS and JavaScript — project website (`index.html`)
- Python (Flask) — backend serving the site and the material calculator (`app.py`)
